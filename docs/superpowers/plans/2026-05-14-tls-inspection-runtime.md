# TLS Inspection Runtime Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make TLS inspection fail closed and policy-driven: upstream egress is enforced with `SO_BINDTODEVICE`, redirect nft state follows snapshots, and untrusted upstream certificates are handled by `TlsDecisionEngine`.

**Architecture:** Keep existing `SessionMeta` plaintext direction work as baseline. Add focused runtime units: `UpstreamConnector` for route lookup and bound upstream sockets, `TlsRedirectManager` for nft lifecycle, and post-handshake TLS policy in `TlsDecisionEngine`. `MitmProxy` becomes an executor that asks these units for decisions and streams, with no direct upstream `TcpStream::connect()`.

**Tech Stack:** Rust 2024, Tokio, rustls/tokio-rustls, socket2, nftables command runner, protobuf3/prost, NestJS TypeScript snapshot mapper.

```rust
use tokio::net::{TcpSocket, TcpStream};

#[derive(Clone)]
pub struct UpstreamConnectContext {
    pub session_id: Uuid,
    pub peer: SocketAddr,
    pub original_dst: SocketAddr,
    pub mode: InspectionMode,
    pub sni: Option<String>,
}

#[derive(Debug, Error)]
pub enum UpstreamConnectError {
    #[error("no route for upstream destination {dst}")]
    NoRoute { dst: SocketAddr },
    #[error("resolved upstream interface {index} is missing for {dst}")]
    InterfaceMissing { dst: SocketAddr, index: SystemInterfaceId },
    #[error("resolved upstream interface {index} has empty name for {dst}")]
    InterfaceNameEmpty { dst: SocketAddr, index: SystemInterfaceId },
    #[error("failed to bind upstream socket to {iface} for {dst}")]
    BindFailed { dst: SocketAddr, iface: String, source: std::io::Error },
    #[error("failed to connect upstream socket to {dst} via {iface}")]
    ConnectFailed { dst: SocketAddr, iface: String, source: std::io::Error },
}

#[async_trait]
pub trait UpstreamConnector: Send + Sync {
    async fn connect(
        &self,
        dst: SocketAddr,
        context: &UpstreamConnectContext,
    ) -> Result<TcpStream, UpstreamConnectError>;
}

pub trait EgressRouteLookup: Send + Sync {
    fn route_lookup(&self, ip: IpAddr) -> Option<SystemInterfaceId>;
}

impl EgressRouteLookup for RoutingTable {
    fn route_lookup(&self, ip: IpAddr) -> Option<SystemInterfaceId> {
        RoutingTable::route_lookup(self, ip)
    }
}
```

Implement `LinuxUpstreamConnector`:

```rust
pub struct LinuxUpstreamConnector {
    routes: Arc<dyn EgressRouteLookup>,
    interfaces: Arc<dyn InterfaceMonitor>,
    socket_connector: Arc<dyn BoundSocketConnector>,
}

impl LinuxUpstreamConnector {
    pub fn new(
        routes: Arc<RoutingTable>,
        interfaces: Arc<dyn InterfaceMonitor>,
    ) -> Self {
        Self {
            routes,
            interfaces,
            socket_connector: Arc::new(LinuxBoundSocketConnector),
        }
    }

    pub fn with_socket_connector(
        routes: Arc<dyn EgressRouteLookup>,
        interfaces: Arc<dyn InterfaceMonitor>,
        socket_connector: Arc<dyn BoundSocketConnector>,
    ) -> Self {
        Self { routes, interfaces, socket_connector }
    }

    pub fn preflight(&self) -> std::io::Result<()> {
        self.socket_connector.preflight()
    }

    fn resolve_egress_interface(
        &self,
        dst: SocketAddr,
    ) -> Result<SystemInterface, UpstreamConnectError> {
        let Some(index) = self.routes.route_lookup(dst.ip()) else {
            return Err(UpstreamConnectError::NoRoute { dst });
        };
        let Some(interface) = self.interfaces.get_by_index(index) else {
            return Err(UpstreamConnectError::InterfaceMissing { dst, index });
        };
        if interface.name.trim().is_empty() {
            return Err(UpstreamConnectError::InterfaceNameEmpty { dst, index });
        }
        Ok(interface)
    }
}
```

Implement `UpstreamConnector` for `LinuxUpstreamConnector`:

```rust
#[async_trait]
impl UpstreamConnector for LinuxUpstreamConnector {
    async fn connect(
        &self,
        dst: SocketAddr,
        context: &UpstreamConnectContext,
    ) -> Result<TcpStream, UpstreamConnectError> {
        let interface = self.resolve_egress_interface(dst)?;
        tracing::info!(
            event = "tls.upstream.connect.started",
            session_id = %context.session_id,
            peer = %context.peer,
            dst = %dst,
            original_dst = %context.original_dst,
            resolved_iface = %interface.name,
            mode = ?context.mode,
            sni = context.sni.as_deref().unwrap_or(""),
            "TLS upstream connect started"
        );
        let stream = self.socket_connector
            .connect_bound(dst, &interface.name)
            .await
            .map_err(|source| {
                tracing::warn!(
                    event = "tls.upstream.connect.failed",
                    session_id = %context.session_id,
                    dst = %dst,
                    resolved_iface = %interface.name,
                    error = %source,
                    "TLS upstream connect failed"
                );
                if source.kind() == std::io::ErrorKind::PermissionDenied {
                    UpstreamConnectError::BindFailed { dst, iface: interface.name.clone(), source }
                } else {
                    UpstreamConnectError::ConnectFailed { dst, iface: interface.name.clone(), source }
                }
            })?;
        tracing::info!(
            event = "tls.upstream.connect.bound",
            session_id = %context.session_id,
            dst = %dst,
            resolved_iface = %interface.name,
            "TLS upstream socket bound"
        );
        Ok(stream)
    }
}
```

```rust
#[async_trait]
impl BoundSocketConnector for LinuxBoundSocketConnector {
    fn preflight(&self) -> std::io::Result<()> {
        let socket = Socket::new(Domain::IPV4, Type::STREAM, Some(Protocol::TCP))?;
        socket.bind_device(Some(b"lo"))

    async fn connect_bound(&self, dst: SocketAddr, iface: &str) -> std::io::Result<TcpStream> {
        let socket = Socket::new(Domain::for_address(dst), Type::STREAM, Some(Protocol::TCP))?;

        let std_stream: std::net::TcpStream = socket.into();

    }
```

Add manager implementation:

```rust
impl TlsRedirectManager {
    pub fn new() -> Self {
        Self::with_applier(Arc::new(NftRedirectApplier))
    }

    pub fn with_applier(applier: Arc<dyn RedirectApplier>) -> Self {
        Self {
            applier,
            applied: Mutex::new(None),
        }
    }

    pub fn reconcile(
        &self,
        desired: RedirectDesiredState,
    ) -> Result<(), RedirectReconcileError> {
        let previous = self.applied.lock().clone();
        let old_interfaces = previous
            .as_ref()
            .map(|state| state.desired.capture_interfaces.clone())
            .unwrap_or_default();
        let generation = previous.as_ref().map_or(1, |state| state.generation + 1);

        tracing::info!(
            event = "tls.redirect.reconcile.started",
            generation,
            old_interfaces = ?old_interfaces,
            new_interfaces = ?desired.capture_interfaces,
            ports = ?desired.inspection_ports,
            listen_addr = %desired.listen_addr,
            "TLS redirect reconcile started"
        );

        if !desired.enabled {
            self.applier.uninstall()?;
            *self.applied.lock() = None;
            tracing::info!(event = "tls.redirect.reconcile.uninstalled", generation, reason = "disabled");
            return Ok(());
        }

        if desired.capture_interfaces.is_empty() {
            self.applier.uninstall()?;
            *self.applied.lock() = None;
            tracing::warn!(event = "tls.redirect.reconcile.uninstalled", generation, reason = "empty_interfaces");
            return Err(RedirectReconcileError::NoCaptureInterfaces);
        }

        if previous.as_ref().is_some_and(|state| state.desired == desired) {
            return Ok(());
        }

        let redirect = TransparentRedirect::new(
            desired.listen_addr,
            desired.capture_interfaces.clone(),
            desired.inspection_ports.clone(),
            desired.local_addresses.clone(),
        )?;
        self.applier.install(&redirect)?;
        *self.applied.lock() = Some(RedirectAppliedState { desired: desired.clone(), generation });
        tracing::info!(
            event = "tls.redirect.reconcile.installed",
            generation,
            interfaces = ?desired.capture_interfaces,
            ports = ?desired.inspection_ports,
            listen_addr = %desired.listen_addr,
            "TLS redirect installed"
        );
        Ok(())
    }
}

impl TlsRedirectReconciler for TlsRedirectManager {
    fn reconcile(&self, desired: RedirectDesiredState) -> Result<(), RedirectReconcileError> {
        TlsRedirectManager::reconcile(self, desired)
    }
}
```

```markdown
# TLS Inspection Runtime

## Flow

Transparent redirect sends configured TLS ports from sniffed interfaces to the MITM listener. `MitmProxy` reads the original destination, peeks ClientHello, asks `TlsDecisionEngine` for the pre-handshake decision, connects upstream through `UpstreamConnector`, asks `TlsDecisionEngine` for the post-handshake certificate decision, then relays plaintext through `InspectionRelay`.

## Required Privileges

Strict upstream egress enforcement is Linux-specific and uses `SO_BINDTODEVICE`. TLS MITM requires root, `CAP_NET_RAW`, or equivalent privileges. Startup runs a preflight check when TLS inspection is enabled. Runtime still fails closed on every route, interface, bind, or connect failure.

## Fail-Closed Cases

- No route for the upstream destination.
- Resolved interface id missing from `InterfaceMonitor`.
- Empty resolved interface name.
- `SO_BINDTODEVICE` failure.
- Upstream TCP connect failure.
- TLS inspection enabled with no sniffed interfaces.
- Untrusted upstream certificate when policy action is `Block`.

## Redirect Reconcile

`TlsRedirectManager` owns nft redirect state. Startup and accepted snapshots call `reconcile()` with desired state. Disabled TLS inspection uninstalls redirect. Enabled TLS inspection with empty sniffed interfaces uninstalls stale redirect and rejects the snapshot. Changed state replaces the full nft table from a rendered ruleset.

## Untrusted Upstream Certificates

`RecordingVerifier` records upstream trust. `TlsDecisionEngine` decides whether to block or continue with Untrust CA. Block happens before `accept_client_tls`.

## Debug Events

- `tls.redirect.reconcile.started`
- `tls.redirect.reconcile.installed`
- `tls.redirect.reconcile.uninstalled`
- `tls.redirect.reconcile.failed`
- `tls.upstream.connect.started`
- `tls.upstream.connect.bound`
- `tls.upstream.connect.failed`
- `tls.decision.post_handshake`
- `tls.upstream.cert.untrusted.blocked`
- `tls.upstream.cert.untrusted.forward_untrust_ca`

## Known Limits

- QUIC and HTTP/3 are not inspected by this MITM path.
- ECH can hide useful SNI unless blocked or mitigated through DNS policy.
- mTLS and certificate pinning can cause client-side handshake failures.
- Historical ciphertext cannot be decrypted without session keys.
- Strict egress enforcement requires Linux because it relies on `SO_BINDTODEVICE`.
```

## Implementation Notes

- Do not introduce a production `strict|permissive` config. Runtime production behavior is strict-only.
- Test fakes are allowed under `#[cfg(test)]` and through trait injection.
- Keep direct `TcpStream::connect()` in `dual_session.rs` tests and `decryption_mirror.rs`; this plan only removes upstream direct connects from `mitm_proxy.rs`.
- Prefer structured `tracing` events for new runtime diagnostics. Add protobuf event messages only if a consumer needs them during implementation.
- If backend generated proto changes are large, keep them in the same commit as the proto schema change so TypeScript tests see a consistent contract.
